    Колебание функции и критерий Коши

    Предел означает, что все значения функции достаточно близко к одному числу. Но иногда искать это число неудобно: например, для сложной осциллирующей функции заранее неясно, каким оно могло бы быть. Можно задать другой вопрос: становятся ли значения функции сколь угодно близкими друг к другу, если аргументы достаточно приблизить к точке? Критерий Коши утверждает, что для вещественных значений ответ на этот вопрос полностью определяет существование конечного предела.

    Нам понадобятся определение предела функции и полнота вещественной прямой. В отличие от определения предела, в формулировке критерия не фигурирует неизвестное число-предел.

    Разброс значений на множестве

    Заголовок раздела «Разброс значений на множестве»

    Пусть f:E→Rf:E\to\mathbb Rf:E→R и A⊆EA\subseteq EA⊆E — непустое множество. Колебанием функции на AAA назовём наименьшую верхнюю грань расстояний между двумя её значениями:

    ω(f;A)=sup⁡{∣f(x)−f(y)∣:x,y∈A}∈[0,+∞].\omega(f;A)=\sup\{|f(x)-f(y)|:x,y\in A\}\in[0,+\infty].ω(f;A)=sup{∣f(x)−f(y)∣:x,y∈A}∈[0,+∞].

    Иными словами, это диаметр множества значений f(A)f(A)f(A). Если fff ограничена на AAA, то

    ω(f;A)=sup⁡x∈Af(x)−inf⁡x∈Af(x).\omega(f;A)=\sup_{x\in A}f(x)-\inf_{x\in A}f(x).ω(f;A)=x∈Asup​f(x)−x∈Ainf​f(x).

    Если функция не ограничена, колебание может быть бесконечным. При включении множеств разброс не увеличивается: из A⊆BA\subseteq BA⊆B следует ω(f;A)≤ω(f;B)\omega(f;A)\le\omega(f;B)ω(f;A)≤ω(f;B).

    Теперь зафиксируем предельную точку aaa области EEE и будем смотреть на значения функции в проколотых окрестностях:

    Dδ={x∈E:0<∣x−a∣<δ},ωδ(f,a)=ω(f;Dδ).D_\delta=\{x\in E:0<|x-a|<\delta\},\qquad \omega_\delta(f,a)=\omega(f;D_\delta).Dδ​={x∈E:0<∣x−a∣<δ},ωδ​(f,a)=ω(f;Dδ​).

    Когда δ\deltaδ уменьшается, множество аргументов сужается, поэтому ωδ(f,a)\omega_\delta(f,a)ωδ​(f,a) не возрастает. Его предел при δ→0+\delta\to0+δ→0+ существует в расширенном смысле; назовём его колебанием функции в точке:

    ω(f;a)=inf⁡δ>0ωδ(f,a).\omega(f;a)=\inf_{\delta>0}\omega_\delta(f,a).ω(f;a)=δ>0inf​ωδ​(f,a).

    Значение f(a)f(a)f(a) в это определение не входит: как и предел, колебание в точке описывает поведение функции в проколотых окрестностях.

    Критерий Коши для конечного предела

    Заголовок раздела «Критерий Коши для конечного предела»

    Пусть aaa — предельная точка EEE, а f:E→Rf:E\to\mathbb Rf:E→R. Тогда следующие условия равносильны:

    1. существует конечный предел lim⁡E∋x→af(x)\lim_{E\ni x\to a}f(x)limE∋x→a​f(x);
    2. для каждого ε>0\varepsilon>0ε>0 найдётся δ>0\delta>0δ>0, при котором ω(f;Dδ)<ε;\omega(f;D_\delta)<\varepsilon;ω(f;Dδ​)<ε;
    3. колебание функции в точке равно нулю: ω(f;a)=0\omega(f;a)=0ω(f;a)=0.

    Условие 2 можно записать без обозначения колебания: для всех x,y∈Ex,y\in Ex,y∈E, если 0<∣x−a∣<δ0<|x-a|<\delta0<∣x−a∣<δ и 0<∣y−a∣<δ0<|y-a|<\delta0<∣y−a∣<δ, то ∣f(x)−f(y)∣<ε|f(x)-f(y)|<\varepsilon∣f(x)−f(y)∣<ε. Важно, что сравниваются любые две точки проколотой окрестности, а не только значения в одной выбранной последовательности.

    Доказательство

    Заголовок раздела «Доказательство»

    Пусть сначала f(x)→L∈Rf(x)\to L\in\mathbb Rf(x)→L∈R. Для заданного ε>0\varepsilon>0ε>0 выберем окрестность, в которой ∣f(x)−L∣<ε/3|f(x)-L|<\varepsilon/3∣f(x)−L∣<ε/3. Для любых двух допустимых точек этой окрестности

    ∣f(x)−f(y)∣≤∣f(x)−L∣+∣f(y)−L∣<2ε3.|f(x)-f(y)|\le |f(x)-L|+|f(y)-L|<\frac{2\varepsilon}{3}.∣f(x)−f(y)∣≤∣f(x)−L∣+∣f(y)−L∣<32ε​.

    Значит, колебание там не превосходит 2ε/32\varepsilon/32ε/3, а потому строго меньше ε\varepsilonε. Так доказано условие 2. Оно равносильно условию 3 по определению предела невозрастающей величины ωδ(f,a)\omega_\delta(f,a)ωδ​(f,a).

    Теперь предположим условие 2. Так как aaa — предельная точка EEE, для каждого n≥1n\ge1n≥1 можно выбрать xn∈Ex_n\in Exn​∈E так, что 0<∣xn−a∣<1/n0<|x_n-a|<1/n0<∣xn​−a∣<1/n. Для любого ε>0\varepsilon>0ε>0 найдётся проколотая окрестность, на которой колебание меньше ε\varepsilonε. Все члены последовательности, начиная с достаточно большого номера, лежат в ней; следовательно, последовательность f(xn)f(x_n)f(xn​) фундаментальна. Полнота R\mathbb RR даёт число L∈RL\in\mathbb RL∈R, к которому она сходится.

    Докажем, что к тому же LLL стремятся значения функции при любом приближении xxx к aaa. Для заданного ε>0\varepsilon>0ε>0 возьмём δ\deltaδ так, чтобы ω(f;Dδ)<ε/3\omega(f;D_\delta)<\varepsilon/3ω(f;Dδ​)<ε/3. Если x∈Dδ/2x\in D_{\delta/2}x∈Dδ/2​, то и все достаточно поздние xnx_nxn​ принадлежат DδD_\deltaDδ​. Поэтому

    ∣f(x)−f(xn)∣<ε3.|f(x)-f(x_n)|<\frac{\varepsilon}{3}.∣f(x)−f(xn​)∣<3ε​.

    Переходя к пределу при n→∞n\to\inftyn→∞, получаем ∣f(x)−L∣≤ε/3<ε|f(x)-L|\le\varepsilon/3<\varepsilon∣f(x)−L∣≤ε/3<ε. Это верно для всех x∈Dδ/2x\in D_{\delta/2}x∈Dδ/2​, значит, f(x)→Lf(x)\to Lf(x)→L. Доказана достаточность; полнота вещественных чисел использована именно при переходе от фундаментальности к существованию числа LLL.

    Два осциллирующих примера

    Заголовок раздела «Два осциллирующих примера»

    Для f(x)=xsin⁡(1/x)f(x)=x\sin(1/x)f(x)=xsin(1/x) при x≠0x\ne0x=0 имеем ∣f(x)∣≤∣x∣|f(x)|\le |x|∣f(x)∣≤∣x∣. Если x,y∈Dδx,y\in D_\deltax,y∈Dδ​ около нуля, то

    ∣f(x)−f(y)∣≤∣f(x)∣+∣f(y)∣<2δ.|f(x)-f(y)|\le |f(x)|+|f(y)|<2\delta.∣f(x)−f(y)∣≤∣f(x)∣+∣f(y)∣<2δ.

    Следовательно, ω(f;Dδ)≤2δ→0\omega(f;D_\delta)\le2\delta\to0ω(f;Dδ​)≤2δ→0, и по критерию существует конечный предел. Более того, оценка ∣f(x)∣≤∣x∣|f(x)|\le|x|∣f(x)∣≤∣x∣ сразу показывает, что предел равен 000.

    У функции g(x)=sin⁡(1/x)g(x)=\sin(1/x)g(x)=sin(1/x) на каждом проколотом интервале 0<∣x∣<δ0<|x|<\delta0<∣x∣<δ встречаются значения 111 и −1-1−1: достаточно взять подходящие числа x=1/(π/2+2πn)x=1/(\pi/2+2\pi n)x=1/(π/2+2πn) и x=1/(3π/2+2πn)x=1/(3\pi/2+2\pi n)x=1/(3π/2+2πn) при больших натуральных nnn. Поскольку значения синуса лежат между −1-1−1 и 111, на каждом таком интервале

    ω(g;Dδ)=2,\omega(g;D_\delta)=2,ω(g;Dδ​)=2,

    и ω(g;0)=2\omega(g;0)=2ω(g;0)=2. Критерий исключает конечный предел, не требуя угадывать его и подбирать специальную последовательность, опровергающую каждый возможный ответ.

    Колебание бесконечно у функции h(x)=1/xh(x)=1/xh(x)=1/x на проколотых окрестностях нуля. Это также согласуется с отсутствием конечного предела. При этом h(x)→+∞h(x)\to+\inftyh(x)→+∞ справа — другой вид предела, к которому сформулированный выше конечный критерий неприменим.

    Упражнения

    Заголовок раздела «Упражнения»

    1. Сужение области. Пусть A,B⊆EA,B\subseteq EA,B⊆E — непустые множества и A⊆BA\subseteq BA⊆B. Докажите, что ω(f;A)≤ω(f;B)\omega(f;A)\le\omega(f;B)ω(f;A)≤ω(f;B). Почему колебание на одноточечном множестве равно нулю?

    Решение

    Каждая пара x,y∈Ax,y\in Ax,y∈A также принадлежит BBB, поэтому множество расстояний ∣f(x)−f(y)∣|f(x)-f(y)|∣f(x)−f(y)∣, по которому берётся супремум для AAA, является подмножеством множества расстояний для BBB. Супремум не может увеличиться при переходе к подмножеству. Если A={x}A=\{x\}A={x}, единственная разность равна ∣f(x)−f(x)∣=0|f(x)-f(x)|=0∣f(x)−f(x)∣=0.

    2. Колебание функции знака. Пусть s(x)=1s(x)=1s(x)=1 при x>0x>0x>0 и s(x)=−1s(x)=-1s(x)=−1 при x<0x<0x<0. Найдите ω(s;Dδ)\omega(s;D_\delta)ω(s;Dδ​) и ω(s;0)\omega(s;0)ω(s;0) для E=R∖{0}E=\mathbb R\setminus\{0\}E=R∖{0}.

    Решение

    В каждой проколотой окрестности есть точки обоих знаков. Значения равны 111 и −1-1−1, поэтому наибольшая разность равна 222. Это верно при любом δ>0\delta>0δ>0, следовательно, колебание в нуле равно 222.

    3. Уменьшающаяся амплитуда. Пользуясь критерием Коши, докажите существование конечного предела x2sin⁡(1/x)x^2\sin(1/x)x2sin(1/x) при x→0x\to0x→0 и найдите его.

    Решение

    Для x,y∈Dδx,y\in D_\deltax,y∈Dδ​ имеем ∣x2sin⁡(1/x)−y2sin⁡(1/y)∣≤∣x∣2+∣y∣2<2δ2|x^2\sin(1/x)-y^2\sin(1/y)|\le |x|^2+|y|^2<2\delta^2∣x2sin(1/x)−y2sin(1/y)∣≤∣x∣2+∣y∣2<2δ2. Значит, колебание не превосходит 2δ22\delta^22δ2 и стремится к нулю. По критерию предел конечен. Из ∣x2sin⁡(1/x)∣≤x2|x^2\sin(1/x)|\le x^2∣x2sin(1/x)∣≤x2 следует, что он равен 000.

    4. Предел ограничивает колебание. Докажите также непосредственное следствие критерия: если f(x)→L∈Rf(x)\to L\in\mathbb Rf(x)→L∈R, то fff ограничена на некоторой проколотой окрестности точки aaa.

    Решение

    Взяв в определении предела ε=1\varepsilon=1ε=1, получаем проколотую окрестность, где ∣f(x)−L∣<1|f(x)-L|<1∣f(x)−L∣<1. Тогда ∣f(x)∣≤∣L∣+1|f(x)|\le|L|+1∣f(x)∣≤∣L∣+1, то есть значения ограничены.

    Колебание превращает вопрос о пределе в вопрос о разбросе значений. Для вещественных функций исчезающий разброс достаточен благодаря полноте R\mathbb RR; в неполном пространстве значений одной фундаментальности может не хватить.
