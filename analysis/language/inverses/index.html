    Инъекции, сюръекции и обратимость

    Можно ли по выходу функции восстановить вход? Для этого выход должен действительно достигаться и не должен получаться от двух разных входов. Эти два требования называются сюръективностью и инъективностью.

    Понадобятся определение отображения, образ и прообраз из предыдущей статьи. Здесь мы введём три типа отображений, научимся составлять функции и докажем точное условие обратимости.

    Инъекция: выход не теряет различия

    Заголовок раздела «Инъекция: выход не теряет различия»

    Отображение f:A→Bf:A\to Bf:A→B называется инъективным, или инъекцией, если

    ∀x1,x2∈A:f(x1)=f(x2) ⟹ x1=x2.\forall x_1,x_2\in A:\quad f(x_1)=f(x_2)\ \Longrightarrow\ x_1=x_2.∀x1​,x2​∈A:f(x1​)=f(x2​) ⟹ x1​=x2​.

    Равносильная формулировка: разные входы имеют разные выходы. Для каждого y∈By\in By∈B прообраз f−1({y})f^{-1}(\{y\})f−1({y}) содержит не более одного элемента — возможно, ни одного.

    Чтобы доказать инъективность, обычно берут произвольные x1,x2x_1,x_2x1​,x2​, предполагают равенство значений и выводят равенство входов. Например, для f:R→Rf:\mathbb R\to\mathbb Rf:R→R, f(x)=2x−5f(x)=2x-5f(x)=2x−5:

    2x1−5=2x2−5⟹x1=x2.2x_1-5=2x_2-5\quad\Longrightarrow\quad x_1=x_2.2x1​−5=2x2​−5⟹x1​=x2​.

    Чтобы опровергнуть инъективность, достаточно одной пары разных входов с одинаковым выходом. Квадрат на R\mathbb RR не инъективен: (−2)2=22(-2)^2=2^2(−2)2=22, хотя −2≠2-2\ne2−2=2.

    Сюръекция: достигаются все цели

    Заголовок раздела «Сюръекция: достигаются все цели»

    Отображение f:A→Bf:A\to Bf:A→B называется сюръективным, или сюръекцией, если

    ∀y∈B ∃x∈A:f(x)=y.\forall y\in B\ \exists x\in A:\quad f(x)=y.∀y∈B ∃x∈A:f(x)=y.

    То есть f(A)=Bf(A)=Bf(A)=B. Для каждого элемента целевого множества прообраз непуст. Единственность такого входа не требуется.

    Порядок кванторов существенен: для каждого yyy разрешено выбирать свой xxx. Не требуется один вход, подходящий ко всем выходам.

    Для f(x)=2x−5f(x)=2x-5f(x)=2x−5 на R\mathbb RR произвольное y∈Ry\in\mathbb Ry∈R достигается при x=(y+5)/2x=(y+5)/2x=(y+5)/2. Этот xxx принадлежит области определения, и подстановка даёт f(x)=yf(x)=yf(x)=y, что доказывает сюръективность.

    Сюръективность зависит от целевого множества. Правило a↦0a\mapsto0a↦0, b↦1b\mapsto1b↦1 задаёт сюръекцию {a,b}→{0,1}\{a,b\}\to\{0,1\}{a,b}→{0,1}, но не сюръекцию {a,b}→{0,1,2}\{a,b\}\to\{0,1,2\}{a,b}→{0,1,2}: во втором случае 222 не достигается.

    Для отрицания сюръективности нужно предъявить y∈By\in By∈B, для которого подходящего входа нет. Квадрат R→R\mathbb R\to\mathbb RR→R не сюръективен, поскольку отрицательные числа не являются квадратами.

    Биекция: ровно один вход для каждого выхода

    Заголовок раздела «Биекция: ровно один вход для каждого выхода»

    Биекция — отображение, одновременно инъективное и сюръективное. Его определение можно записать одним условием:

    ∀y∈B ∃!x∈A:f(x)=y.\forall y\in B\ \exists!x\in A:\quad f(x)=y.∀y∈B ∃!x∈A:f(x)=y.

    Не путайте это с определением любой функции. У функции каждому входу соответствует единственный выход; у биекции дополнительно каждому выходу из BBB соответствует единственный вход.

    Три конечных примера показывают, что инъективность и сюръективность независимы:

    ОтображениеИнъективно?Сюръективно?
    {a,b}→{0,1,2}\{a,b\}\to\{0,1,2\}{a,b}→{0,1,2}: a↦0a\mapsto0a↦0, b↦1b\mapsto1b↦1ДаНет: не достигается 222
    {a,b,c}→{0,1}\{a,b,c\}\to\{0,1\}{a,b,c}→{0,1}: a↦0a\mapsto0a↦0, b↦1b\mapsto1b↦1, c↦1c\mapsto1c↦1Нет: b,cb,cb,c имеют общий выходДа
    {a,b}→{0,1}\{a,b\}\to\{0,1\}{a,b}→{0,1}: a↦1a\mapsto1a↦1, b↦0b\mapsto0b↦0ДаДа

    В терминах стрелок инъекция запрещает слияние стрелок, сюръекция запрещает выходы без входящих стрелок, а биекция требует по одной входящей стрелке к каждому выходу.

    Единственное отображение ∅→B\varnothing\to B∅→B всегда инъективно: разных входов нет. Оно сюръективно и биективно ровно при B=∅B=\varnothingB=∅, поскольку его образ пуст.

    Композиция: выполнить два правила подряд

    Заголовок раздела «Композиция: выполнить два правила подряд»

    Пусть f:A→Bf:A\to Bf:A→B и g:B→Cg:B\to Cg:B→C. Их композиция g∘f:A→Cg\circ f:A\to Cg∘f:A→C задаётся правилом

    (g∘f)(x)=g(f(x)).(g\circ f)(x)=g(f(x)).(g∘f)(x)=g(f(x)).

    Сначала применяется fff, затем ggg: порядок чтения записи — справа налево. Композиция корректна, поскольку выход fff лежит в области определения ggg. В более общем случае достаточно, чтобы все значения fff попадали в область определения ggg.

    Для f(x)=x+2f(x)=x+2f(x)=x+2 и g(x)=3xg(x)=3xg(x)=3x на R\mathbb RR:

    (g∘f)(x)=3x+6,(f∘g)(x)=3x+2.(g\circ f)(x)=3x+6,\qquad (f\circ g)(x)=3x+2.(g∘f)(x)=3x+6,(f∘g)(x)=3x+2.

    Обе композиции здесь существуют, но различны. В других примерах обратный порядок может вообще не иметь смысла из-за несовместимых областей.

    Композиция ассоциативна: для h:C→Dh:C\to Dh:C→D

    h∘(g∘f)=(h∘g)∘f.h\circ(g\circ f)=(h\circ g)\circ f.h∘(g∘f)=(h∘g)∘f.

    Обе стороны отображают AAA в DDD и на каждом xxx дают h(g(f(x)))h(g(f(x)))h(g(f(x))). Скобки не влияют на результат, но менять порядок функций нельзя.

    Тождественное отображение id⁡A:A→A\operatorname{id}_A:A\to AidA​:A→A задаётся правилом id⁡A(x)=x\operatorname{id}_A(x)=xidA​(x)=x. Для f:A→Bf:A\to Bf:A→B:

    f∘id⁡A=f,id⁡B∘f=f.f\circ\operatorname{id}_A=f,\qquad \operatorname{id}_B\circ f=f.f∘idA​=f,idB​∘f=f.

    Эти равенства проверяются на произвольном входе; индексы у тождественных отображений фиксируют нужные множества.

    Когда существует обратное отображение

    Заголовок раздела «Когда существует обратное отображение»

    Отображение g:B→Ag:B\to Ag:B→A называется обратным к f:A→Bf:A\to Bf:A→B, если выполнены оба равенства:

    g∘f=id⁡A,f∘g=id⁡B.g\circ f=\operatorname{id}_A,\qquad f\circ g=\operatorname{id}_B.g∘f=idA​,f∘g=idB​.

    Первое возвращает исходный вход после применения fff. Второе гарантирует, что выбранный вход действительно приводит к исходному выходу.

    Теорема. Отображение f:A→Bf:A\to Bf:A→B имеет обратное тогда и только тогда, когда оно биективно. В этом случае обратное отображение единственно.

    Доказательство необходимости. Пусть ggg — обратное. Если f(x1)=f(x2)f(x_1)=f(x_2)f(x1​)=f(x2​), применяем ggg к обеим сторонам и получаем x1=x2x_1=x_2x1​=x2​. Следовательно, fff инъективно. Для произвольного y∈By\in By∈B элемент x=g(y)x=g(y)x=g(y) принадлежит AAA и удовлетворяет f(x)=f(g(y))=yf(x)=f(g(y))=yf(x)=f(g(y))=y. Следовательно, fff сюръективно.

    Доказательство достаточности. Пусть fff биективно. Для каждого y∈By\in By∈B существует единственный x∈Ax\in Ax∈A с f(x)=yf(x)=yf(x)=y. Определим g(y)g(y)g(y) именно как этот xxx. Уникальность входа делает правило однозначным, а существование — определённым на всём BBB.

    По построению f(g(y))=yf(g(y))=yf(g(y))=y. Для любого x∈Ax\in Ax∈A единственным входом, дающим f(x)f(x)f(x), является сам xxx, поэтому g(f(x))=xg(f(x))=xg(f(x))=x. Оба требуемых равенства доказаны. Наконец, любое другое обратное должно выбирать тот же единственный вход для каждого yyy, значит, совпадает с ggg.

    Обратное обозначают f−1:B→Af^{-1}:B\to Af−1:B→A. Для f(x)=2x−5f(x)=2x-5f(x)=2x−5 оно имеет формулу f−1(y)=(y+5)/2f^{-1}(y)=(y+5)/2f−1(y)=(y+5)/2. Обозначение не означает 1/f(y)1/f(y)1/f(y).

    Теперь различайте две записи: f−1(y)f^{-1}(y)f−1(y) — значение обратной функции, если она существует; f−1(D)f^{-1}(D)f−1(D) для D⊆BD\subseteq BD⊆B — прообраз множества, определённый всегда. При биективном fff прообраз DDD совпадает с образом DDD под обратным отображением, поэтому обозначения согласованы.

    Почему одного равенства недостаточно

    Заголовок раздела «Почему одного равенства недостаточно»

    Возьмём A={a}A=\{a\}A={a}, B={0,1}B=\{0,1\}B={0,1}, f(a)=0f(a)=0f(a)=0 и g(0)=g(1)=ag(0)=g(1)=ag(0)=g(1)=a. Тогда g(f(a))=ag(f(a))=ag(f(a))=a, то есть g∘f=id⁡Ag\circ f=\operatorname{id}_Ag∘f=idA​. Но f(g(1))=0≠1f(g(1))=0\ne1f(g(1))=0=1, так что второе равенство нарушено.

    Первое равенство делает ggg левым обратным, но не двусторонним обратным. При нём fff обязательно инъективно, однако может не быть сюръективным. Аналогично из f∘g=id⁡Bf\circ g=\operatorname{id}_Bf∘g=idB​ следует сюръективность fff, но инъективность может не выполняться.

    Инъективное f:A→Bf:A\to Bf:A→B всегда можно рассматривать как биекцию A→f(A)A\to f(A)A→f(A): мы меняем целевое множество на фактический образ. Это даёт обратное на f(A)f(A)f(A), а не обязательно на всём BBB.

    Проверьте себя

    Заголовок раздела «Проверьте себя»

    1. Классификация. Для f:Z→Zf:\mathbb Z\to\mathbb Zf:Z→Z, f(n)=2n+1f(n)=2n+1f(n)=2n+1, проверьте инъективность и сюръективность. Здесь Z\mathbb ZZ — целые числа в школьном смысле.

    Подсказка и решение

    Из 2n1+1=2n2+12n_1+1=2n_2+12n1​+1=2n2​+1 следует n1=n2n_1=n_2n1​=n2​, поэтому функция инъективна. Она не сюръективна: значение 000 потребовало бы n=−1/2n=-1/2n=−1/2, а это не целое число. Если целевым множеством объявить все нечётные целые, получится биекция с обратным правилом y↦(y−1)/2y\mapsto(y-1)/2y↦(y−1)/2.

    2. Проверка обеих сторон. Найдите обратное к f:R→Rf:\mathbb R\to\mathbb Rf:R→R, f(x)=4−3xf(x)=4-3xf(x)=4−3x, и проверьте оба равенства композиций.

    Подсказка и решение

    Уравнение y=4−3xy=4-3xy=4−3x даёт g(y)=(4−y)/3g(y)=(4-y)/3g(y)=(4−y)/3. Подстановка показывает g(f(x))=(4−(4−3x))/3=xg(f(x))=(4-(4-3x))/3=xg(f(x))=(4−(4−3x))/3=x и f(g(y))=4−3(4−y)/3=yf(g(y))=4-3(4-y)/3=yf(g(y))=4−3(4−y)/3=y. Поэтому g=f−1g=f^{-1}g=f−1.

    3. Что можно узнать из композиции? Пусть f:A→Bf:A\to Bf:A→B и g:B→Cg:B\to Cg:B→C. Докажите: если g∘fg\circ fg∘f инъективно, то fff инъективно; если g∘fg\circ fg∘f сюръективно, то ggg сюръективно.

    Подсказка и доказательство

    Если f(x1)=f(x2)f(x_1)=f(x_2)f(x1​)=f(x2​), то g(f(x1))=g(f(x2))g(f(x_1))=g(f(x_2))g(f(x1​))=g(f(x2​)). Инъективность композиции даёт x1=x2x_1=x_2x1​=x2​.

    Для любого z∈Cz\in Cz∈C сюръективность композиции даёт x∈Ax\in Ax∈A с g(f(x))=zg(f(x))=zg(f(x))=z. Тогда y=f(x)∈By=f(x)\in By=f(x)∈B — подходящий вход для ggg.

    Нельзя автоматически заключать инъективность ggg на всём BBB: композиция проверяет ggg только на f(A)f(A)f(A). Нельзя и заключать сюръективность fff на BBB: для достижения всех zzz могут быть достаточны лишь некоторые элементы BBB.

    4. Обратное к композиции. Для биекций f:A→Bf:A\to Bf:A→B, g:B→Cg:B\to Cg:B→C докажите, что g∘fg\circ fg∘f биективно и

    (g∘f)−1=f−1∘g−1.(g\circ f)^{-1}=f^{-1}\circ g^{-1}.(g∘f)−1=f−1∘g−1.
    Подсказка и доказательство

    Проверим оба равенства для кандидата k=f−1∘g−1:C→Ak=f^{-1}\circ g^{-1}:C\to Ak=f−1∘g−1:C→A. Ассоциативность даёт

    k∘(g∘f)=f−1∘(g−1∘g)∘f=f−1∘f=id⁡A,k\circ(g\circ f)=f^{-1}\circ(g^{-1}\circ g)\circ f =f^{-1}\circ f=\operatorname{id}_A,k∘(g∘f)=f−1∘(g−1∘g)∘f=f−1∘f=idA​,(g∘f)∘k=g∘(f∘f−1)∘g−1=g∘g−1=id⁡C.(g\circ f)\circ k=g\circ(f\circ f^{-1})\circ g^{-1} =g\circ g^{-1}=\operatorname{id}_C.(g∘f)∘k=g∘(f∘f−1)∘g−1=g∘g−1=idC​.

    Значит, обратное существует. По доказанной теореме композиция биективна, а её единственное обратное равно kkk. Обратите внимание: отменять действия нужно в обратном порядке.

    Что запомнить и где читать дальше

    Заголовок раздела «Что запомнить и где читать дальше»

    Инъекция означает не более одного входа на выход, сюръекция — не менее одного, биекция — ровно один. Обратное на всём целевом множестве существует ровно у биекции. Для проверки обратимости нужны обе композиции с тождественными отображениями.

    Далее — отношения и классы эквивалентности: они описывают, какие входы можно считать одинаковыми в выбранном смысле.
