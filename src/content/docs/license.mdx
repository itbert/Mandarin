Код проекта **Mandarin** распространяется по лицензии **Apache License 2.0**. Полный текст лицензии находится в [файле LICENSE репозитория](https://github.com/itbert/Mandarin/blob/main/LICENSE).

Лицензия разрешает использовать, изменять и распространять код при соблюдении её условий, включая сохранение уведомлений и указание изменений. Код предоставляется без гарантий. При использовании проекта руководствуйтесь полным текстом лицензии.

Учебные статьи содержат самостоятельное изложение, примеры и упражнения. Указанные в них книги служат литературными ориентирами; тексты этих книг в репозиторий не включены. Отдельная лицензия для учебных материалов пока не установлена.
