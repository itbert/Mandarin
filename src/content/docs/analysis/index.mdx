## Как читать

В каждой статье есть объяснение идеи, точные определения, доказательства и упражнения. Сначала попробуйте решить задачу самостоятельно, затем откройте подсказку или разбор. Рисунок помогает понять утверждение, но доказательство остаётся отдельной частью текста.

Слева находятся главы и опубликованные статьи. Внутри статьи — оглавление по вопросам; внизу — переход к следующему материалу. Уже знакомую тему можно пропустить и вернуться к ней по ссылкам из следующих статей.
